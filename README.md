# pectus-backend

Estrutura basica de backend em TypeScript com Express.

## Requisitos

- Node.js 20+

## Como rodar

1. Instalar dependencias:

```bash
npm install
```

2. Rodar em desenvolvimento:

```bash
npm run dev
```

3. Build de producao:

```bash
npm run build
npm start
```

## Endpoint inicial

- `GET /health` retorna `{ "status": "ok" }`
